# Handwriting Exercise: What Pressure Is This Note Carrying?

Date: 2026-05-16

Source: Follow-up exercise from the Gemini concepts-as-paths return packet.

## Purpose

Use one handwritten page to test the idea that a concept is a path rather than a fixed object.

## Exercise

Choose one older note that still feels unfinished, hazy, or strangely important.

Write by hand for one page using these prompts:

1. What movement did this note first capture?
2. What pressure is the note still carrying?
3. What has changed in me since I first wrote or encountered it?
4. What field does my attention create around it now?
5. What future return is this note asking for?

## Return Method

After writing, place the page back into the Read-Write loop:

- Inscription: the old note.
- Return: today's handwritten page.
- Projection: ask AI to summarise the movement without flattening it.
- Revision: mark what still carries pressure.
- Next return: choose one phrase to revisit later.
