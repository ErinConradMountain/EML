# Read-Write Model Working Section

Purpose: collect and develop the Read-Write Model as one of EML's central mechanisms.

The Read-Write Model studies learning as a loop of inscription, projection, return, revision, and re-entry. It is not only a workflow for writing the book. It is one of the book's core arguments: the human model is trained through disciplined return to externalised thought.

## What Belongs Here

- Analytical studies focused on read-write cycles.
- Source maps pointing to large journal files.
- Diagrams of inscription, projection, re-entry, drift, anchoring, and feedback.
- Short readings that can later move to `05-Assets/Readings/`.
- Chapter seeds for Part II Grammar and Part III Circuits in Practice.
- Open questions that need another handwritten cycle.

## Default File Types

| Type | Pattern | Notes |
| --- | --- | --- |
| Study index | `YYYY-MM-read-write-model-study-index.md` | Monthly map of source material and routes |
| Analytical note | `YYYY-MM-DD-read-write-<topic>.md` | Step 2 style study |
| Reading seed | `YYYY-MM-DD-reading-<topic>.md` | Candidate for `05-Assets/Readings/` |
| Diagram brief | `YYYY-MM-DD-diagram-<topic>.md` | Candidate for `05-Assets/Diagrams/` |
