# External Coordination Quickstart (EML)

Purpose: short onboarding guide for the external side of the project so both sides stay aligned.

## One-Screen Summary
- This repository is the authoritative EML book workspace (structure, outputs, assets).
- The external side runs ChatGPT sessions and returns outputs here for filing.
- Weekly alignment depends on the current weekly knowledge file, the portable ChatGPT knowledge file, and the weekly intake template.

## What to Use Every Week
- Weekly knowledge file: `02-Intake/Weekly/2026-W20/EML-Project-Update-Conversation-Knowledge-Surface-2026-05-16.md`
- Portable ChatGPT knowledge file: `09-ChatGPT-Knowledge-Feed/01-ChatGPT-Project-Knowledge/Current-EML-Project-Knowledge.md`
- Weekly template: `05-Assets/Templates/Weekly-Intake-Template.md`
- ChatGPT instructions: `08-Admin/Instructions/Journal-Reading-ChatGPT-Custom-Instructions-2026-01-26.md`

If the external side uses a different knowledge filename, record it in the full guide:
`08-Admin/Instructions/External-Project-Coordination-Guide-2026-01-26.md`.

## How the Loop Works
1. Handwritten notes are captured and shared with ChatGPT.
2. ChatGPT produces Step outputs (1-6) with tags (Book Part, EML layers).
3. Outputs return to this repository for filing under `03-Working/`.
4. Key ideas/diagrams/readings are promoted into `05-Assets/` and `06-Lexicon/`.
5. Weekly intake files in `02-Intake/Weekly/` are updated to preserve the record.

## Non-Negotiables
- Preserve the author's voice and distinctive phrases.
- One step per response unless the user asks otherwise.
- Respect weekend ingestion mode (listening/condensing).
- End file-ready outputs with a proposed save location.

For full details, roles, and file maps, see:
`08-Admin/Instructions/External-Project-Coordination-Guide-2026-01-26.md`.
