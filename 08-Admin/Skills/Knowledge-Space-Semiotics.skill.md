# Skill: Knowledge Space and Semiotics Development

Use this skill when material concerns knowledge space, visual grammar, page navigation, colour logic, markers, semiotic sequencing, satellite perspective, staged observation, or thought as terrain.

## Goal

Develop EML's visual and semiotic grammar so the book can make learning visible, traceable, and revisable through stable marks, pages, diagrams, colours, and spatial relations.

## Procedure

1. Identify the visual or semiotic operation: marker, colour, boundary, page route, perspective, field, object, observer, sequence, or terrain.
2. Tag the material by Book Part and EML Layer.
3. Decide whether the output is a diagram brief, visual-language rule, lexicon entry, circuit, reading, or chapter seed.
4. Preserve Erin's phrases where they carry conceptual force.
5. Route the output:
   - study -> `03-Working/Knowledge-Space-Semiotics/`
   - visual rule -> `05-Assets/Visual-Language/`
   - diagram -> `05-Assets/Diagrams/`
   - circuit -> `05-Assets/Circuits/`
   - definition -> `06-Lexicon/Definitions/`
   - book section -> `04-Book/Part-02-Grammar/` or `04-Book/Part-03-Circuits/`

## Output Contract

Every output should include:

- Source used.
- Visual/semiotic operation.
- Book Part.
- EML Layer(s).
- Proposed save location.
- One test question for the next diagram or handwritten page.
