# Skill: Read-Write Model Development

Use this skill when a note, output, or planning question concerns the Read-Write Model, human-AI read-write loops, handwriting as inscription, re-entry, drift, anchoring, or training the human model.

## Inputs

- Handwritten notes or transcripts.
- ChatGPT return packets.
- Existing Step 1-3 outputs.
- April 2026 journal material.

## Procedure

1. Identify the loop stage: inscription, projection, re-entry, revision, or drift control.
2. Tag the material by Book Part and EML Layer.
3. Decide whether the output is a definition, analytical study, diagram brief, circuit, reading, or chapter seed.
4. Preserve phrases that carry Erin's voice.
5. Route the output:
   - study -> `03-Working/Read-Write-Model/`
   - definition -> `06-Lexicon/Definitions/`
   - diagram -> `05-Assets/Diagrams/`
   - circuit -> `05-Assets/Circuits/`
   - book section -> `04-Book/Part-02-Grammar/` or `04-Book/Part-03-Circuits/`

## Output Contract

Every output should include:

- Source used.
- Read-Write loop stage.
- Book Part.
- EML Layer(s).
- Proposed save location.
- One question for the next handwritten cycle.
