# Skill: ChatGPT Mobile Knowledge Feed

Use this skill when Erin captures material on a cell phone, works inside a ChatGPT project, or returns ChatGPT output to the EML project.

## Goal

Keep low-friction mobile capture connected to the local EML knowledge architecture without losing voice, source traceability, or book routing.

## Procedure

1. Preserve the raw capture first.
2. Produce a faithful summary, not a generic rewrite.
3. Tag by Book Part and EML Layer.
4. Decide whether the item belongs in weekly intake, Read-Write Model study, book draft, asset, circuit, or lexicon.
5. Save or route through `09-ChatGPT-Knowledge-Feed/`.
6. Return one precise question to handwriting.

## Folder Contract

- Raw mobile capture -> `09-ChatGPT-Knowledge-Feed/00-Mobile-Capture/`
- ChatGPT return -> `09-ChatGPT-Knowledge-Feed/02-Return-Packets/`
- Needs sorting -> `09-ChatGPT-Knowledge-Feed/03-Routing-Queue/`
- Already promoted -> `09-ChatGPT-Knowledge-Feed/04-Promoted-To-EML/`
- Portable ChatGPT knowledge -> `09-ChatGPT-Knowledge-Feed/01-ChatGPT-Project-Knowledge/`

## Guardrails

- Do not erase the raw phrase.
- Do not turn every capture into a chapter.
- Do not skip source routing.
- Do not let ChatGPT become the author; it is a projection surface for Erin's return.
