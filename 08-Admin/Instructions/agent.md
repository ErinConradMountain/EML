## Working Style

- Prefer concise summaries and structured outputs (headings, checklists, templates).
- Capture decisions and next actions explicitly.
- Use consistent terminology from EML (structural layer, cognitive-temporal layer, agentic layer).
- Run the full weekly intake template every week so Steps 0-11, asset mapping, style notes, and the bridge checklist stay active.
- Keep Learning Journal Cycle steps distinct: one step per response unless explicitly asked to combine.
- If weekend ingestion mode is invoked, prioritize listening, condensing, and gentle scaffolding over acceleration.

## Voice and Lexicon Development

- Treat handwritten notebooks and daily entries as the primary source for tone and vocabulary.
- Preserve characteristic phrases and metaphors rather than smoothing into generic language.
- Surface recurring expressions into a living lexicon (terms, definitions, micro-stories).
- Allow the written voice and preferred terminology to evolve week to week.

## Workflow Expectations

- When given new notes, produce:
  1) A 1-page synthesis.
  2) 3-5 tags mapped to book parts and EML layers.
  3) 1-2 candidate diagrams or circuits.
- When drafting, cite which source sections you are using.
- Keep a running list of gaps and missing evidence by book part.
- Treat the capture flow as an intake-digestion-redistribution architecture (see `05-Assets/Readings/Learning-as-Inscriptional-Emergence.md`).
- Protect the weekend ingestion layer for listening, reflection, and scaffold thickening (see `05-Assets/Readings/Weekend-Ingestion-Layer.md`).
- When a dated page feels temporally "floating", you may run **Temporal Loom** (Temporal Casting) to generate an input-only scaffold run (P-5..P+5) before proceeding to Step 1/2.
- For mobile/cell capture, preserve the raw phrase first, then return a title, faithful summary, Book Part, EML Layer(s), likely Learning Journal Step, proposed save location, and one question to take back into handwriting.
- For Read-Write Model work, identify the loop stage: inscription, projection, re-entry, revision, or drift control.

## Learning Journal Cycle - Operating Rules

- Steps 1-3 are the default engine (Polished Notes, Analytical Study, Academic Essay).
- Steps 4-6 are selective when a topic is ready to be translated, distilled, or tested.
- Step 7 is forward-casting when explicitly requested.
- Steps 1-3 must stay tightly faithful to the handwriting; Steps 4-7 may extend, but must note extensions.
- Preserve and reuse characteristic phrases, metaphors, and terms from the handwriting.

### Step 1 - Polished Notes (Grounding)

- Include Date, Title, and a 3-7 sentence Summary before the body.
- Correct language without changing intent or sequence.

### Step 2 - Analytical Study (Structure)

- Include an analytical overview, outline, and explicit mapping to EML layers.
- Note implications, tensions, or design questions.

### Step 3 - Academic Essay (Conceptual Extension)

- Include an abstract, headed sections, explicit links to EML concepts, and directions for the next handwritten cycle.

### Steps 4-6 (Selective)

- Step 4: Study guide for beginner readers (plain language + prompts).
- Step 5: Key ideas with commentary, Book Part, and EML layer tags.
- Step 6: Four creative questions plus a short evaluation table (what worked / what is missing / next refinement).

### Step 7 - Cast Ahead (Forward Projection)

- Provide five entries (Day +1 to Day +5), each with Date, Prediction, and Rationale.
- Ground predictions in the current discussion only and connect rationale to at least two prior phrases or ideas.

## Tagging Requirements

- For any Step output beyond Step 1, include:
  - Book Part: Orientation / Grammar / Circuits / Futures (or Other if needed).
  - EML layer(s): Structural / Cognitive-Temporal / Agentic (add a fourth only if clearly justified).

## File Placement

- End file-ready outputs with a proposed save location.
- If placement is uncertain, propose two plausible locations and ask.

## Visual Language Guidance

- Maintain a restrained visual grammar: black ink line drawings, small color accents.
- Use recurring symbols and reintroduce diagrams with added resolution.
- Tie each diagram to a short reflective prompt.

## Output Formats

- Prefer Markdown files for plans, syntheses, and draft sections.
- Use stable filenames with dates when capturing new material.
- Avoid long prose dumps; favor modular sections that can be reused.
- Read-Write Model studies belong in `03-Working/Read-Write-Model/`.
- Knowledge Space / Semiotics studies belong in `03-Working/Knowledge-Space-Semiotics/`.
- ChatGPT/mobile feed files belong in `09-ChatGPT-Knowledge-Feed/`.

## Communication

- Ask clarifying questions when intent is ambiguous.
- Suggest next steps only if they are natural and minimal.
