# EML Codex Agent Guide

Purpose: give Codex, Copilot, ChatGPT exports, and other assistants one clear operating contract for the EML project.

## Project Identity

EML means Educational Modelling Language. This project is both a book and a working learning system. The book should become a model in book form: field notebook, technical manual, reflective sketchbook, and visual grammar.

The central study is the Read-Write Model: handwriting anchors thought; AI projection externalises structure; human re-reading contests, rewrites, and trains the human model through return.

## Working Rules

- Read project guidance before editing: start with this file, then `08-Admin/Instructions/agent.md`, `07-Guides/EML-Project-Orientation.md`, and `EML-Folder-Structure.md`.
- Treat `.github/copilot-instructions.md`, `.github/instructions/`, and `.github/agents/` as the active workspace instruction layer; use `08-Admin/Instructions/` as the detailed project memory and external handoff layer.
- Preserve Erin's voice, metaphors, and recurring phrases. Do not flatten notes into generic academic prose.
- Keep source material traceable. Raw or original material stays in `00-Inbox/`, `01-Source/`, or `Journal Notes/`; promoted outputs point back to source rather than silently replacing it.
- Prefer small, file-placeable outputs with explicit routing: source, step, book part, EML layer, and proposed save location.
- For governance, education, privacy, and human-development claims, treat dignity, consent, role, auditability, and learner agency as first-order requirements.
- Do not use destructive Git commands unless explicitly requested.

## Routing Model

Every new item should move through these gates:

1. Capture: save raw material without rewriting it.
2. Clarify: create or update a short intake record.
3. Digest: run the correct Learning Journal Cycle step.
4. Classify: tag by Book Part and EML Layer.
5. Promote: route to Read-Write Model study, book draft, asset, circuit, or lexicon.
6. Return: update the ChatGPT knowledge feed when the project rules or current focus change.

For extracted archives, preserve the original archive, create routed working copies, and add a monthly integration map plus promotion receipt.

## Book Parts

- Orientation: lived experience, inheritance, self-location, ethical drift, formative action.
- Grammar: symbols, operations, diagrams, casting, crucible, knowledge space, drift vectors.
- Circuits in Practice: classroom scenes, AI interactions, Read-Write loops, MVP, staff routines.
- Futures: agentic systems, technics, delegated agency, human-AI ecology.

## EML Layers

- Structural: nodes, links, flows, constraints, forms, knowledge-space topology.
- Cognitive-Temporal: repetition, delay, casting, drift, memorisation, formation over time.
- Agentic: learners, educators, AI, notebooks, diagrams, tools, prompts, and delegated agency.
