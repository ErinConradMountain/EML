**Created:** 2026-05-02

**EML layer(s):** Structural; Agentic

## Claim

Colour should operate as functional grammar, not decoration. In EML diagrams, colour should carry stable roles that help the reader recognise structure, time, agency, emergence, and movement.

## Working Palette

| Colour | Provisional function |
| --- | --- |
| Black ink | Base structure, line, mark, relation |
| Blue | Structural organisation and scaffolding |
| Yellow | Emergence, attention, signal, first appearance |
| Green | Growth, development, recursive life |

## Design Rule

Do not use colour merely to make a diagram attractive. Use colour only when it clarifies a role, relation, movement, or layer.

## Next Test

Apply this palette to the Read-Write Model loop and to a page-as-navigation diagram. If the colours do not help the reader predict meaning, revise the palette.
