## Diagram Claim

The page is not a passive surface. It is a navigation system where marks, colour, position, and sequence help the learner move through knowledge space.

## Visual Structure

Use one page outline with:

- entry point

## Relationship to Read-Write Model

The page-as-navigation system is the terrain on which the Read-Write Model operates. Writing places marks into navigable relation; reading returns through those marks; revision changes the route.
