# Diagram Brief: Concept as Path in a Field of Study

Date: 2026-05-16

Source: Gemini conversation pasted into Codex chat and routed through the EML knowledge feed.

## Purpose

Create a restrained EML diagram showing how attention draws a movement from latent space into a bounded field, where staged return lets a concept become legible over time.

## Visual Grammar

- Black ink line drawing.
- One small colour accent for the selected path.
- Avoid decorative colour fields.
- Use a hand-drawn frame or boundary to show the field of study.
- Keep the page quiet: one main path, one boundary, no crowded side notes.
- Show fading with lighter line weight, not with decorative effects.

## Core Sequence

```text
Latent Space
    |
    v
Selection by Attention
    |
    v
Bounded Field of Study
    |
    v
Note / Inscription
    |
    v
Staged Return
    |
    v
Concept as Path
    |
    v
Future Vector
```

## Composition

Place the diagram on a landscape page.

Left side:

- A loose, unbounded cloud labelled `Latent Space`.
- Several faint possible lines should sit inside it, but only one is selected.

Centre:

- A simple rectangular or hand-drawn boundary labelled `Field of Study`.
- The selected line crosses the boundary and becomes darker.
- Inside the frame, place a small mark labelled `Note / Inscription`.

Right side:

- The path loops once or twice through `Staged Return`.
- Each loop should pass back near the note, then move forward.
- The final line exits as `Future Vector`.

## Diagram Logic

The drawing should show that attention does not simply find an object already waiting in the world. Attention selects a movement and creates the field in which that movement can become observable.

The field is therefore not background. It is a working frame. It gives the note pressure, limits the space of investigation, and makes return possible.


## Labels

- Latent Space: unbounded possibility.
- Selection: the act of attention.
- Frame: the boundary that makes study possible.
- Note: the anchor of emergence.
- Return: fading and resurfacing.
- Path: provenance, pressure, trajectory.

## Visual Constraints

- Do not draw the concept as a box or final object.
- Do not stack the stages vertically as a ladder unless a second version is needed.
- Keep the emphasis on a moving line inside a bounded field.
- Use one accent colour only on the selected path.

## Reflective Prompt

What did this note make observable that was previously only a background pressure?
