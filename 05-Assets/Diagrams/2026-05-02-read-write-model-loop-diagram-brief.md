**Created:** 2026-05-02

**EML layer(s):** Structural; Cognitive-Temporal; Agentic

## Diagram Claim

The Read-Write Model is a loop of human inscription, AI projection, human re-entry, and revision. The loop trains the human model when return becomes more precise and more ethically situated over time.

## Visual Structure

Use a restrained black-ink loop with four primary stations:

1. Handwriting / inscription
2. AI projection / external structure
3. Human re-reading / re-entry
4. Revision / new inscription

Add two outer forces:

- Drift vector: shows where repeated passes are moving the work.
- Anchor: shows where the work is stabilised enough to return to.

## Page Use

- Left page: visual loop with marginal arrows and small annotations.
- Right page: reflection on how the loop trains the human rather than the machine.
