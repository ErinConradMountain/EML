# EML

Educational Modelling Language is a research-and-writing project about
handwriting, AI projection, re-reading, and the training of the human model.

## Public Website

The repository includes a static public website at `index.html`. When GitHub
Pages is enabled for this repository, it can be served from:

https://erinconradmountain.github.io/EML/

The site links into the main project documents, book drafts, lexicon, and asset
folders so the general public can read the project as a navigable UI while the
source material remains traceable in GitHub.
