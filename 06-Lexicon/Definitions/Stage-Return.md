# Stage Return

Status: Working definition

Source: Developed from EML project discussion and the Gemini conversation pasted into Codex on 2026-05-16.

## Definition

Stage return is the process by which a concept becomes legible through repeated re-entry. A thought does not arrive complete. It is inscribed, left to fade, returned to under a new context, and progressively clarified by the pressure of later understanding.

## EML Function

Stage return explains how learning happens across time:

- the first note anchors a movement;
- later return brings a changed reader back to the same mark;
- the concept carries old pressure into a new field;
- the idea becomes more usable because it has survived multiple contexts.
