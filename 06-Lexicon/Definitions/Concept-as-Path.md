# Concept as Path

Status: Working definition

Source: Developed from the Gemini conversation pasted into Codex on 2026-05-16 and promoted through the EML knowledge-feed return cycle.

## Definition

A concept as path is a concept understood by its movement rather than by a fixed definition at one moment. It is shaped by where it has come from, how it has moved, what pressure it carries, and what future return it invites.

## EML Function

This term shifts EML from a static layered diagram into a developmental system.

In a static model, a concept can look like a stored object: a definition, note, quote, or category.

In a developmental model, the concept is read through:

- provenance: what gave rise to it;
- re-entry: how it has been returned to and revised;
- pressure: what tension it is carrying;
- trajectory: what it may become next.

## Relationship to Stage Return

Stage return is the method by which a concept-as-path becomes legible. The learner returns to an inscription repeatedly, under changing contexts, until the thought develops enough structure to be used.

## Relationship to Field-Centred Study

A concept-as-path needs a field. Selection and framing create the bounded region in which the path can be observed. Without a field, the concept risks becoming either an isolated object or a wandering abstraction.

## Working Phrase

A concept is not a thing at a moment. A concept is a path.
