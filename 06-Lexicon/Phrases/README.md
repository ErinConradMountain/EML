# Phrases

Purpose: hold recurring expressions, micro-stories, and characteristic wording that carry Erin's voice.

Use this folder when:
- a phrase recurs across notes, essays, or guides
- a line acts as a stable orientation phrase for the project
- a micro-story or metaphor should be preserved without forcing it into a formal definition

This lane is intentionally separate from `Definitions/` so the project's fingerprint language stays visible.
