# 06-Lexicon

Purpose: stabilize the project's language across definitions, terms, and recurring phrases.

## Folder Map

| Folder | Use | Current state |
| --- | --- | --- |
| `Definitions/` | Formal or semi-formal concept entries | Active |
| `Terms/` | Shorter concept names, provisional labels, and routing terms | Empty, scaffolded |

## Working Rules

- Preserve Erin's fingerprint vocabulary rather than flattening it.
- Use standard layer names: Structural, Cognitive-Temporal, Agentic.
- Add new entries here when a term starts recurring across working studies, guides, or book seeds.
- Keep definitions traceable to source notes, working studies, or book drafts.
