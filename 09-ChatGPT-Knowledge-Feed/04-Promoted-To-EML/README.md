# Promoted to EML

Purpose: keep receipts for mobile/ChatGPT material that has been absorbed into the main project.

Create one dated receipt per promotion when a return packet results in new or updated files.

## Receipt Pattern

`YYYY-MM-DD-promotion-receipt-<short-topic>.md`

Each receipt should include:

- source packet
- files updated
- book part and EML layer
- remaining question
- whether the ChatGPT project knowledge file needs updating
