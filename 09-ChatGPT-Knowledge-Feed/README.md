# ChatGPT Knowledge Feed

Purpose: hold the latest portable structure for Erin's ChatGPT project, especially the mobile/cell capture workflow that collects fragments and feeds them back into the EML project.

This folder is not a replacement for the main EML archive. It is a controlled membrane between mobile capture, ChatGPT project work, and the local EML book system.

## Folder Map

| Folder | Use |
| --- | --- |
| `00-Mobile-Capture/` | Phone-originated notes, photo descriptions, voice-note summaries, rough prompts |
| `01-ChatGPT-Project-Knowledge/` | Current portable knowledge files to attach or paste into ChatGPT |
| `02-Return-Packets/` | Dated packets of ChatGPT outputs returning to this project |
| `03-Routing-Queue/` | Items waiting to be classified into EML sections |
| `04-Promoted-To-EML/` | Receipts for material already promoted into the main folders |

## Operating Loop

1. Capture on cell: photo, voice, quick note, diagram description, or question.
2. ChatGPT turns the capture into a structured return packet.
3. Save the return packet in `02-Return-Packets/`.
4. Route each packet through `03-Routing-Queue/`.
5. Promote stable material into `02-Intake/`, `03-Working/`, `04-Book/`, `05-Assets/`, or `06-Lexicon/`.
6. Record the promotion in `04-Promoted-To-EML/`.
