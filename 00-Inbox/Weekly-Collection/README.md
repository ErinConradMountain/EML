# Weekly Collection

Drop new weekly files here before processing.

What belongs here:
- Handwritten scans or photos
- Raw transcripts (OCR or typing)
- Quick context notes from the week
- Chat exports (chat.html, conversations.json) and any export metadata

Naming:
- `YYYY-MM-DD-<short-desc>.<ext>`
- For chat exports, use a folder like `YYYY-WW-Chat-Export/`.

How to file this week:
- Drop new scans/photos/transcripts here first.
- Create the weekly folder in `02-Intake/Weekly/YYYY-WW/`.
- Move cleaned sources to `01-Source/Handwritten/` or `01-Source/Transcripts/`.
- Add or update the weekly intake file in the weekly folder.

Preserved exports:
- Chat export folders in this lane are treated as raw source.
- Historical paths inside `chat.html`, `conversations.json`, or export metadata may be outdated.
- Do not rewrite those files just to normalize old references; document drift in admin notes instead.
